## [0.5.0](https://github.com/BrianEstrada/oxlint-deslopify/compare/v0.4.0...v0.5.0) - 2026-10-11

### Breaking changes

- **rules:** Add no-object-parameters to both presets ([#12](https://github.com/BrianEstrada/oxlint-deslopify/pull/12))

## [0.4.0](https://github.com/BrianEstrada/oxlint-deslopify/compare/v0.3.0...v0.4.0) - 2026-10-11

### Breaking changes

- **rules:** Add 11 rules against casts, unknown and module mocks ([#10](https://github.com/BrianEstrada/oxlint-deslopify/pull/10))
  - `no-chained-type-assertions`, `require-safety-comment-for-type-assertion`, `no-unknown-parameters`, `no-unknown-returns`, `no-unknown-type-aliases`, `no-runtime-typeof`, `no-reflect-get`, `no-reflect-apply`, `no-module-mocking`, `no-conditional-empty-object-spread` and `no-reduce-accumulator-copy`, all in both presets.
- **presets:** Add oxc/no-accumulating-spread to recommended

## [0.3.0](https://github.com/BrianEstrada/oxlint-deslopify/compare/v0.2.0...v0.3.0) - 2026-10-04

### Breaking changes

- **presets:** Add slop and tidiness rules to opinionated
  - Projects extending opinionated may see new lint errors.

## [0.2.0](https://github.com/BrianEstrada/oxlint-deslopify/releases/tag/v0.2.0) - 2026-10-04

### Breaking changes

- **presets:** Add configs.opinionated and keep recommended to our rules ([#2](https://github.com/BrianEstrada/oxlint-deslopify/pull/2))
  - `configs.recommended` no longer turns on built-in Oxlint rules (func-style, object-shorthand, curly, arrow-body-style, consistent-type-definitions, no-deprecated, no-unsafe-*). Extend `configs.opinionated` to keep them.

## 0.1.0 - 2026-10-04

### Features

- Add oxlint-plugin-deslopify with four rules and a recommended preset
  - `multiline-object`, `no-graphql-cast`, `no-property-type-lookup` and `simple-ternary`.
